Description

The instance name ({{.InstanceName}}) is still set by [instance] name in the config file, because it is baked into the app manifest at startup.

Markdown is supported. HTML is sanitized before it is published.

Rules

One rule per line. Shown on the About page, on the registration form, and returned by /api/v1/instance/rules. Leave empty to publish no rules.

Contact

Published to clients and on the About page. The contact account is set by contact_username in the config file, and falls back to the first administrator.

Terms of service

Markdown. Published at /terms and through /api/v1/instance/terms_of_service. Empty means this server publishes no terms, and both return 404.
